# IS-451-Business-Data-Analytics

This course focuses on modern business data analytics and the practical use of programming
for turning data into decisions. We will cover core data mining and machine learning
techniques, and apply them to real-world business datasets using R for data wrangling,
visualization, modeling, and communication of results. The course also introduces generative
AI as a new tool in the data analyst’s workflow. Students will learn how AI can accelerate
common analytics tasks, while developing the habits needed to validate AI-generated outputs
and ensure analyses remain accurate, reproducible, and responsible.

The key objectives of this course are three-fold: (1) to provide you with a theoretical and
practical understanding of core data mining concepts and techniques; and (2) to provide you
with hands-on data analysis experience using various statistical methods and major statistical
software (R package) to analyze complex real-world data in business and industry, with the
aim of creating insight and value. (3) Understand the fundamental concepts of generative AI
and its applications in data analytics. Learn how to use AI tools and frameworks to enhance
business decision making.

Through this course, students should be able to:
• Analyze a business situation to determine information management needs.
• Explain different methods of data mining
• Select an appropriate data mining technique for a specific problem
• Use R to mine a prepared data set and interpret the results
