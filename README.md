# IS 451 – Business Data Analytics

A collection of labs, assignments, and outputs from IS 451 – Business Data Analytics. Work is completed in R, covering core data mining and machine learning techniques applied to real-world business datasets.

## Topics Covered

- Linear & Multiple Regression
- Classification & Decision Trees
- Logistic Regression
- Cluster Analysis
- Association Rules
- Text Mining
- Web Analytics
- Generative AI in Data Analytics
