Demo: Toyota cars

Data Description

A large Toyota car dealership offers purchasers of new Toyota cars the option to buy their used car as part of a trade-in. In particular, a new promotion promises to pay high prices for used Toyota Corolla cars for purchasers of a new car. The dealer then sells the used cars for a small profit. To ensure a reasonable profit, the dealer needs to be able to predict the price that the dealerhsip will get for the used cars. For that reason, data were collected on all previous sales of used Toyato Corollas at the dealership. The file ToyotaCorolla.csv includes the sales price and other information on the car, such as its ae, mileage, fuel type, and engine size.

Fit a multiple linear regression for Price

Step 1: Partition the records into 70% training vs. 30% validation with the seed set to 1.

To create a train and validation set, we are going to split randomly this data set into 70% training set and 30% validation set.

We point out the observations we want to include in the training set by randomly sample 70% \(\times\) nrow(car.df) indexes out of nrow(car.df) observations.

Use ?sample to see the documentation.

set.seed(1)  # set seed for reproducing the partition
# Random sample indexes
train.index <- sample(1:nrow(car.df), nrow(car.df)*0.7)

Then, we can build the training and validation set.

# Build training and validation set by indexing
train.df <- car.df[train.index, ]
valid.df <- car.df[-train.index, ]

Step 2: Multiple linear regression

Linear model is the most popular model for making predictions.

We are trying to find the parameters \(\beta\)s which can best describe a continuous response variable \(Y\) as a function of one or more predictor variables \(X\).

Basic formula: \[\begin{equation} Y = \beta_0 + \beta_1x_1 +\beta_2x_2 + \beta_2x_2 + \dots + \beta_px_p + \epsilon \end{equation}\]

Run a multiple linear regression for Price vs. all selected predictors using lm function.

# use lm() to run a linear regression of Spending on all 6 predictors in the training set
car.lm <- lm(Price~., data = train.df)

Here ~ represents formula in R.

  • Y ~ X: Y target, X predictors.
  • Price ~ .: Price target, use all the other variables in the data frame (train.df) as the predictors
  • Price ~ KM + Age_08_04: Use only KM and Age_08_04 as the predictors
  • Price ~ KM:Age_08_04: Use the interation between KM and Age_08_04
  • Price ~ Weight + KM:Age_08_04

Step 3: Intepret the coefficients.

lm() automatically convert Fuel variable to dummies and drop one! The reason is that Fuel is a factor in R after read.csv().

  • Estimates: the value for the \(\beta\)s in our model.
  • Std. Error: the estimation precision of the coefficient
  • Pr(>|t|): P-value measures how likely the coefficient has no effect on the outcome

Interpreting the coffecients for Age_08_04 and Fuel_Type:

  • Age_08_04: When age increases by one unit, the price drops by $124.50 (with else being equal)
  • Fuel_Type :
    • Fuel: {“Diesel”, “Petrol”, “CNG”}
    • Fuel_TypeCNG: base level
    • Comparing to CNG, a car with Diesel is sold $1195.55 more (with else being equal)

Step 4: Make predictions for any data.

  • Use predict function to make predictions of any data set
# use predict() to make predictions on a new set. 
car.lm.pred <- predict(car.lm, valid.df)

Step 5: Evaluate the predictive accuracy of the model by examining its performance on the validation set.

  • We need to use library forecast. Then Use accuracy to compute common accuracy measures.

Recall different accuracy measures: \[ME: = {1 \over n}\sum\limits_{i = 1}^n {({Y_i} - {\hat{Y}_i}) = } {1 \over n}\sum\limits_{i = 1}^n {{e_i}} \] \[MAE: = {1 \over n}\sum\limits_{i = 1}^n {|{e_i}} |\]

\[RMSE: = \sqrt {{1 \over n}\sum\limits_{i = 1}^n {e_i^2} } \]

Load library

library(forecast)

Calculate the prediction accuracy using accuracy function.

#  use options() to ensure numbers are not displayed in scientific notation.
options(scipen=999, digits = 3)

# use accuracy() to compute common accuracy measures.
accuracy(car.lm.pred, valid.df$Price)
##            ME RMSE  MAE   MPE MAPE
## Test set 92.8 1290 1008 0.116   10
